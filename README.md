## 🚀 Öne Çıkan Proje — SignBridge

<div align="center">

<a href="https://github.com/esmasila/SignBridge">
  <img src="https://raw.githubusercontent.com/esmasila/SignBridge/main/docs/banner.png" width="760" alt="SignBridge"/>
</a>

</div>

> **Türk İşaret Dili ↔ Türkçe** arasında **çift yönlü ve gerçek zamanlı** çeviri yapan bir sistem.
> Kameraya yapılan işareti Türkçe metne/sese çevirir; yazılan/söylenen Türkçeyi de **3 boyutlu avatar** ile işaret diline çevirir.

- 🧠 **122 kelimelik** sözlük • **GRU** modeli • **%99.88** doğrulama doğruluğu
- 👁️ **MediaPipe** ile anahtar nokta çıkarımı, **PyTorch** ile eğitim
- 📱 **Web** (Flask) + **Android mobil** (Flutter, **ONNX** ile cihaz üzerinde / çevrimdışı)
- 🗣️ Akıllı NLP ile akıcı cümle, TTS/STT desteği
